# 都道府県ゲーム

中濱Games

都道府県を箱に落として詰めるパズルゲーム。
地図で隣り合う県同士がふれるとくっついて地方になり、47 都道府県ぜんぶつなぐと日本列島が完成します。

## 遊び方

- 箱の上をタップ／ドラッグして位置を決め、指をはなすと県が落ちる（PC は ←→ とスペースキーでも OK）。スマホを左右に傾けても動かせる（メニューで ON/OFF）
- 地図で隣り合う県の「その県の部分」どうしがふれると合体（大きなかたまりでも、となりではない県の部分にふれただけではくっつかない。海をはさむ 北海道–青森、本州–四国、本州–九州、鹿児島–沖縄 もつながる）
- 地方がひとつにそろうと +300 点
- シャッフル（箱をゆらす）は何回でも使える（1.2 秒のクールダウンあり）。スマホを振ってもシャッフルできる（メニューで ON/OFF。iPhone は最初に「動作と方向」の許可が出る）
- 点線より上にあふれたままだとゲームオーバー
- 1 ピースの持ち時間は 8 秒（かんたんは 12 秒）。過ぎるとその位置で自動で落ちる
- 最後のピースを落とすとカウントダウン開始。日本列島は 60 秒、アジア大陸は 90 秒以内に完成させないとタイムアップ
- **ホールド**：今のピースを横に取っておき、あとで入れかえられる（1回落とすまでに1回）
- くっつくと**豆知識**（県庁所在地・名産、国なら首都）がヘッダーの下の帯に出る（箱には重ならない）。メニューで ON/OFF
- 日本列島が完成したら、どんどん世界が広がる：
  **日本 → アジア → ヨーロッパ → アフリカ → 世界**
  - 各ステージは、それまでに完成させた部分（日本 / アジア / ユーラシア / ユーラシア・アフリカ）が金色のピースとして最初から箱に入っていて、そこに国をつなげていく
  - 世界（南北アメリカ・オセアニア）まで完成させたら**全クリア**（スコアは合計）
  - アジア以降は、1つのかたまりの大きさに上限がある（幅は箱の6割・高さは半分まで）。ロシアやユーラシアが大きすぎて置けなくなるのを防ぐ
- 一度たどりついたステージは、タイトルの「エクストラステージ」から直接あそべる

## スコア

| 内訳 | 点数 |
| --- | --- |
| くっつけた | 10 × くっついた数 × コンボ（最大5倍） |
| 地方そろえ | 300 |
| 完成ボーナス | 日本列島 3000・アジア大陸 6000 |

## モード

| | ふつう | かんたん |
| --- | --- | --- |
| ピースの大きさ | 大きめ（くっつくと少し小さくなる） | 少し小さめ |
| あふれライン | 低め | 少し高め |
| ラインを超えてからの猶予 | 2.2 秒 | 3 秒 |
| 次の県 | ランダム | ときどき箱にある県のおとなり |
| ヒント | なし | くっつけられるとなりの県だけが光る |

ベストスコアはモードごとに記録されます。

## みんなで協力（通信）

部屋を作るときに「🤝 協力」を選ぶ（待合室でホストがタップして切りかえも可）。

- みんなで**1つの箱**を使い、入った順に1つずつ県を落とす（上の段に「▶ 番」が出る。自分の番は「あなたの番！」）
- 自分の番の人だけが狙い・落とす・ホールドをできる。**シャッフルはだれでも**（振ってもOK）
- 持ち時間・あふれ・ステージの流れ（日本→世界など）はひとりのときと同じ。完成したら全員で「みんなで完成！」
- 箱の物理計算はホストのスマホで行い、ほかの人には 0.12 秒ごとに箱の様子が届く（`rooms/pref-<番号>-coop`）
- ホストが抜けると、その回は終わり（待合室に戻る）

## みんなで対戦（通信）

1. ひとりが「部屋を作る」→ 4ケタの部屋番号・招待リンク・QR が出る
2. ほかの人は「番号で参加」か、リンク／QR から参加
3. ホストが「スタート」→ 3・2・1 で全員いっせいに開始（県の出る順番は全員同じ）

ステージは部屋を作るとき・待合室（ホスト）のボタンで選べます：
**日本** / **アジア** / **ヨーロッパ** / **アフリカ** / **世界** / **日本→アジア** / **ぜんぶ（日本→世界）**

- 対戦中は 😀 ボタンから**スタンプ**（👍 😂 😱 🔥 うわー ナイス！ まだまだ！）を送れる。相手の箱の上に吹き出しで出る

- 上の段に相手の箱がリアルタイムで小さく表示される
- **おじゃまピース**：地方をそろえると、相手の「つぎ」に**島**（佐渡島・択捉島・対馬・淡路島…）が割り込む。島はほかの県とはくっつかないじゃまもの。親の県（佐渡島なら新潟）にふれると吸収されて +100。ステージごとに島がある（海南島・サハリン・ザンジバル島・タスマニア島など）
- 1位が確定したら WINNER（一番に完成させたとき、またはほかの全員がゲームオーバーで自分の点数が上回ったとき）
- 自分以外の全員が完成させて最下位が確定したら、その場で GAME OVER
- 先にゴール（日本列島 / アジア大陸）を完成させた人が勝ち。だれも完成しなければスコアが高い順
- 結果画面でホストが「もう一回」を押すと、同じ部屋で次の対戦
- 途中で入った人は次の回から参加。ホストが抜けると、次に早く入った人がホストになる

通信は「おでこでお題当て」と同じ Firebase Realtime Database（`odeko-ddb38`）を使っています。
データは `rooms/pref-<部屋番号>` に入るので、お題当ての部屋（`rooms/<番号>`）とはぶつかりません。
作ってから 24 時間たった対戦部屋は、次に部屋を作ったときに自動で消えます。
ランキングは `rooms/pref-ranking/<モード>` に入ります。

Firebase のルールは、`rooms` の下を読み書きできるようにしておく必要があります:

```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".indexOn": ["created"],
      "$room": { ".write": true }
    }
  }
}
```

## 公開のしかた（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 数分後に `https://junnn665.github.io/prefpack/` で遊べる

iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、アイコン付きのアプリのように全画面で遊べます。

ビルド不要の静的ファイルだけで動きます。ローカルで試すなら:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面とデザイン |
| `js/game.js` | ゲーム本体（物理・合体判定・描画） |
| `js/net.js` | みんなで対戦（部屋・参加・おじゃま・順位） |
| `lib/qrcode.min.js` | 招待 QR（qrcode-generator, MIT） |
| `js/prefs.js` | 都道府県の形・隣接データ（自動生成） |
| `js/asia.js` | アジア 46 か国の形・隣接データ（`tools/build_asia.py` で自動生成） |
| `js/world.js` | ヨーロッパ・アフリカ・世界ステージのデータ（`tools/build_world.py` で自動生成） |
| `js/capitals.js` | 各国の首都（日本語名。`tools/build_world.py` で自動生成） |
| `js/facts.js` | 都道府県の県庁所在地・名産 |
| `js/islands.js` | おじゃまピース（島）の形と親（`tools/build_islands.py` で自動生成） |
| `vendor/matter.min.js` | 物理エンジン [Matter.js](https://brm.io/matter-js/)（MIT） |
| `tools/build_prefs.py` | 地図データから `js/prefs.js` を作るスクリプト |
| `tools/build_hulls.js` | 当たり判定を県・国の本当の形に合わせて作るスクリプト |
| `icons/` / `manifest.webmanifest` | ホーム画面用アイコン（iPhone・Android）とアプリ設定 |
| `tools/build_icon.py` | 県の形データからアイコン SVG を作るスクリプト |

### 調整ポイント（`js/game.js` 冒頭）

- `MODES` … モードごとの設定（ピースの大きさ `exp`、あふれライン `lineY`、猶予 `overLimit`、おとなり優先 `neighbor`、ヒント `hint`）
- `SHUFFLE_COOLDOWN` … シャッフルの連打防止時間

### 地図データの作り直し

```sh
curl -LO https://raw.githubusercontent.com/dataofjapan/land/master/japan.geojson
curl -LO https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson
pip install shapely && npm install poly-decomp@0.3.0
python3 tools/build_prefs.py japan.geojson js/prefs.js
curl -LO https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_populated_places.geojson
python3 tools/build_asia.py ne_50m_admin_0_countries.geojson js/asia.js
python3 tools/build_world.py ne_50m_admin_0_countries.geojson ne_50m_populated_places.geojson js/asia.js js/world.js js/capitals.js
node tools/build_hulls.js js/prefs.js js/asia.js js/world.js   # 当たり判定を本当の形（凸パーツの組み合わせ）にする
```

当たり判定の形は URL に `?hitbox` を付けると赤い線で表示されます。

### 更新するとき

`index.html` の `?v=...`（css / js の読み込み部分）を新しい値に変えてからプッシュしてください。
ブラウザが古いファイルを使い続けて動かなくなるのを防げます。
